Official personal developer portfolio for **Rupraj Datta** (`29rdx`), Senior Backend & Cybersecurity Engineer.

## 🛠️ Stack & Architecture
- **HTML5 & Vanilla JS**: Zero bloat, instant 100/100 Lighthouse performance.
- **Modern CSS3**: Dark mode glassmorphism, responsive grid, custom typography.
- **Interactive CLI**: In-browser terminal emulator with command autocompletion and help menu.
- **Automated CI/CD**: Seamless GitHub Actions Pages continuous deployment pipeline.

## 🌐 Live Preview
Visit the live deployment at [29rdx.github.io/my29portfolio](https://29rdx.github.io/my29portfolio/).

### ⌨️ Terminal Keybindings
- `Enter`: Submit command
- `Up / Down`: Cycle previous commands
- `Tab`: Autocomplete command name
- `Ctrl + L`: Clear screen
